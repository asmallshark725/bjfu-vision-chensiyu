# Week5 Day6：候选灯条筛选

在 Day5 轮廓提取的基础上，提取灯条亮中心，并将通过几何筛选的测量结果保存为 Task3 的 Light 对象。

## 编译与运行

依赖：C++17、CMake、OpenCV 4，以及仓库内 task3/include/light.hpp 和 task3/src/light.cpp。

从仓库根目录执行：

```bash
cmake -S week5 -B week5/build
cmake --build week5/build --target day6
cd week5
./build/day6
```

源码位于 `src/day6.cpp`。必须从 `week5` 运行，输入图片在 `data/`，输出保存在 `results/day6/`，路径均相对于运行目录。拖动 Min Brightness 滑条观察掩膜，按 Esc 结束调参；在轮廓结果窗口按键继续，程序保存掩膜并退出。

## 参数与处理流程

1. 三通道最低值默认 200：B、G、R 都严格大于门槛时，像素置白，用于提取接近白色的亮中心。
2. RETR_EXTERNAL 提取外轮廓，几何面积小于 100 的区域被排除。
3. minAreaRect 计算旋转矩形，统一长短边，长宽比至少为 3。
4. 由长边方向计算偏离竖直的倾角，最大允许 20 度。
5. 通过全部条件后，保存中心、长边、短边、带方向角度到 vector<Light>。

角度单位为度，竖直为 0，顺时针为正、逆时针为负。先将长边向量统一朝上，再计算带方向角度。

紫红色轮廓表示通过面积筛选的区域；绿色矩形表示进一步通过长宽比和倾角筛选的候选。
