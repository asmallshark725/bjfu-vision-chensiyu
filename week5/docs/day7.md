# Week5 Day7：灯条颜色识别与装甲板配对

当前版本处理单张图片：先用亮度提取灯条形状，再在灯条周围判断红蓝颜色，最后筛选目标颜色并配对。结果图只标出参与配对的灯条和装甲板中心。

## 编译与运行

依赖 C++17、CMake 3.16 及以上、OpenCV 4。复用 `task3` 中的 `Light` 和 `Armor` 类。

在仓库根目录执行：

```bash
cmake -S week5 -B week5/build
cmake --build week5/build --target day7
cd week5
./build/day7
```

终端提示后，输入 `Red` 或 `Blue`，大小写必须一致。其他输入会提示错误并以状态码 1 退出。

程序目前固定读取 `data/day7_tests/02_multi.jpg`。切换图片时修改 `src/day7.cpp` 中 `cv::imread` 的路径，并重新编译。

## 窗口操作与输出

1. 在 `Day7 Mask` 窗口调整滑条。`Min Brightness` 控制亮中心掩膜，`Color Difference` 控制红蓝色差掩膜。
2. 在图像窗口按 Esc，使用当前阈值执行灯条筛选、局部颜色判断和配对。
3. 查看 `Day7 Contours` 结果，在图像窗口按任意键结束。

亮度掩膜要求 B、G、R 三个通道都高于亮度阈值；蓝色掩膜要求 `B - R` 高于色差阈值，红色掩膜要求 `R - B` 高于色差阈值。亮度和色差分别用于提取形状、采样颜色，因此两个滑条各自控制对应掩膜。`showColorMasks` 默认关闭，改为 `true` 可显示红蓝掩膜窗口。

每次运行覆盖以下文件：

- `results/day7/Day7_contours.png`：结果图，在显示结果时保存。
- `results/day7/Day7_mask.png`：最后一次亮度掩膜，在结果窗口按键结束后保存。

## 当前筛选条件

| 阶段 | 条件或默认值 |
| --- | --- |
| 亮中心 | B、G、R 均大于 200，可通过滑条调整 |
| 红蓝色差 | B 与 R 的差值大于 50，可通过滑条调整 |
| 轮廓面积 | 不小于 50 像素² |
| 灯条长宽比 | 长边 / 短边在 2.5～12 之间 |
| 灯条方向 | 偏离竖直不超过 20° |
| 颜色采样范围 | 最小外接旋转矩形的轴对齐包围框，四周各扩展 `max(2, cvRound(width))` 像素，并裁剪到图像内 |
| 颜色判定 | 红蓝像素总数至少 20，某一颜色占比至少 80%；否则为 `Unknown` |
| 目标颜色 | 仅保留已判定且等于输入颜色的灯条 |
| 配对角度 | 两根灯条角度差不超过 5° |
| 长度相似度 | 较短灯条 / 较长灯条，不小于 0.6 |
| 相对竖直错位 | `yGap / xGap <= 0.25`，且 `xGap > 0` |
| 相对水平间距 | `xGap / meanLength` 在 1～4 之间 |

`xGap`、`yGap` 是两根灯条中心坐标之差的绝对值，`meanLength` 是两根灯条长边的平均值。装甲板中心取两个灯条中心的平均值。灯条带方向角以竖直向上为 0°，顺时针为正。

`Light` 保存几何信息和颜色；`lightRects` 保存相同索引对应的旋转矩形。`pairedLights` 记录哪些灯条参与了配对，最终只绘制这些灯条。

当前还输出试验评分 `pairScore = lengthSimilarity - offsetRatio`。评分尚未用于排序或冲突选择，同一灯条仍可能参与多组配对。

## 后续需要验证的情况

这些阈值来自少量学习图片。小面积或遮挡灯条、透视造成的角度和长度差异、附近其他光源及同色目标靠近时，仍可能漏检或误配。颜色不明确、未配对的灯条不会出现在结果图中；同一灯条目前可以参与多组配对。

当前完成的是图片上的颜色筛选与几何配对，后续还需验证更多场景，再接入视频和位姿估计。
