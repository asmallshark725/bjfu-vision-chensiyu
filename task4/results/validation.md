## 数值与逻辑检查

`ctest --test-dir task4/build --output-on-failure` 已通过：

- 人工构造 35° 整体倾斜的红/蓝灯条，正确颜色各形成一个装甲板，错误颜色无输出。
- 黑图和只有白色、没有颜色证据的亮条无输出。
- 三根相邻灯条不会通过重复使用同一根灯条产生两个框。
- 用已知位姿和配置中的畸变参数投影四角，再用 PnP 恢复平移；误差小于 0.1 mm（理想合成数据检查，不是实机精度）。
- 画面距离等于 `norm(tvec)`；自交点序被拒绝，错误标定分辨率被拒绝。

命令行检查：无效颜色、超出范围的阈值、缺失相机文件/视频、无限重播参数、无窗口与滑条冲突等均返回错误。对已有结果视频再次写入会报错，校验确认原文件不变。

显示分支用离屏环境完成单帧显示/滑条调用检查；完整视频验证使用无窗口模式。实际播放可按 README 命令在 WSLg 窗口中查看。
